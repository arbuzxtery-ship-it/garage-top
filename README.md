# Журнал обслуживания автомобиля

Зачётная работа по ООП. Desktop-приложение на Python и PySide6 для учёта заправок, ремонтов и замены масла.

## Запуск

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Для входа: `admin` / `admin` или `student` / `oop2026`.

## Возможности

- вход по логину и паролю
- выбор машины (в программе их три)
- добавление, изменение и удаление записей
- поиск по описанию и фильтр по типу записи
- сортировка по клику на заголовок столбца
- сводка расходов и пробег следующей замены масла
- при закрытии программы в `report.txt` сохраняется отчёт о входах:

```
+---------------------------------------------------+
| login |       time_in       |       time_out      |
|-------|---------------------|---------------------|
| admin | 12.10.2026 15:59:25 | 12.10.2026 16:12:20 |
+---------------------------------------------------+
```

## Файлы

- `main.py` - запуск программы
- `models.py` - классы `Entity` (абстрактный), `Car`, `ServiceRecord`, `Refuel`, `Repair`, `OilChange`, `User`
- `custom_map.py` - свой класс `CustomMap` вместо `dict`
- `garage.py` - класс `Garage`, хранит машины и записи
- `report.py` - классы `Session` и `Report`
- `data.py` - начальные данные
- `utils.py` - форматирование денег, пробега и дат
- `widgets.py` - свои виджеты (наследники виджетов Qt)
- `windows.py` - окно входа, главное окно и окно записи
- `style.py` - тёмная тема
